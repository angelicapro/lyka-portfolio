# Lyka Portfolio

A responsive, buildless consulting portfolio for Angelica Lei “Lyka” Quebec. Open `index.html` to preview locally. No dependencies or build step are required.

## Publish with GitHub Pages

1. Open https://github.com/angelicapro/lyka-portfolio/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose **main** and **/ (root)**, then click **Save**.
4. Wait for GitHub Pages deployment to finish. Check the repository Actions tab or the Pages settings status.
5. Visit https://angelicapro.github.io/lyka-portfolio/

## Personalize

- Replace the GitHub contact button with an approved public email, LinkedIn profile, or booking link.
- Add approved project case studies with accurate outcomes and permission to publish any client names.
- Review service descriptions and biography before promoting the website.
- Adjust colors in the CSS variables in index.html.

Only public-facing information should be committed. The repository and published site are public.
